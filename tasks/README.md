# The 40 tasks

Fixed list: the same 40 tasks in every run. They are a sample of the public WebVoyager task set (the `browser-use/eval` copy, 588 usable tasks), picked by a published seed; see [How it works](../docs/methodology.md). Machine-readable copy: [tasks.json](tasks.json).

- **Question as run** is what the agent was asked. Where it differs from the published question, only the dates were moved ahead (listed under *What we changed*).
- **Reference answer** is WebVoyager's own. *Stable* ("golden") means a fact that stays true; *may be out of date* ("possible") means it was true when the task was written and the live page may differ today. The judge goes by the live page for the second kind.
